راهنمای فارسی راه‌اندازی سیگنالینگ جایگزین کلاسینو

نکته: ظاهر کلاسینو و تخته‌سفید در index.html حفظ شده و کد برنامه داخل همان فایل است. اما سرور سیگنالینگ نمی‌تواند داخل HTML اجرا شود؛ پوشه signal-server باید جداگانه روی یک سرویس Node.js میزبانی شود.

۱) در GitHub یک مخزن جداگانه برای سرور بساز و فایل‌های داخل پوشه signal-server (server.js و package.json) را در ریشه آن قرار بده.
۲) در سرویس میزبانی که Node.js را پشتیبانی می‌کند، مخزن سرور را به عنوان Web Service منتشر کن. Build Command: npm install ؛ Start Command: npm start. باید آدرس HTTPS عمومی بگیری.
۳) فایل index.html را باز کن و این خط را پیدا کن:
   const SIGNAL_HOST='YOUR-PEERSERVER.onrender.com';
   مقدار را فقط با hostname سرویس واقعی خودت عوض کن، بدون https:// و بدون اسلش. مثال قالب: 'نام-سرویس-خودت.onrender.com'. این فقط مثال قالب است، آدرس واقعی نیست.
۴) همین index.html را در مخزن GitHub Pages کلاسینو جایگزین کن.
۵) دبیر و دانش‌آموز هر دو باید همین نسخه index.html را داشته باشند. دبیر کلاس را بسازد و دانش‌آموز کد را وارد کند.

مهم: این بسته آمادهٔ استقرار است اما سرور از طرف من منتشر نشده و hostname عمومی ندارد؛ تا وقتی مرحله ۲ را انجام ندهی و آدرس واقعی را در SIGNAL_HOST ننویسی، اتصال برقرار نمی‌شود. سرویس رایگان ممکن است بخوابد یا محدودیت داشته باشد. STUN فقط برای پیدا کردن مسیر رسانه است و جای سرور سیگنالینگ یا TURN را نمی‌گیرد. اگر تصویر در بعضی شبکه‌ها باز هم وصل نشود، به TURN معتبر نیاز داریم.
